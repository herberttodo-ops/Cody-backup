## Tone Adjustment Guide

### Making Response Warmer
- Add: "We're so glad you're staying with us!" "We'd love to help!"
- Use exclamation points (sparingly)
- Include personal touches

### Making Response More Professional
- Remove contractions
- Use formal language
- Add title/signature block
- Example: "We are pleased to assist" vs "We're happy to help"

### Handling Angry Customers
1. Acknowledge frustration immediately
2. Apologize (even if not at fault)
3. Show empathy
4. Focus on solution
5. Offer something extra if appropriate

### Closing Options
- **Warm:** "Best," "Warmly," "Take care,"
- **Professional:** "Best regards," "Sincerely,"
- **Grateful:** "With gratitude," "Thank you,"
