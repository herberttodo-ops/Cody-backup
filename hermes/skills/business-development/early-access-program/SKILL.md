# Early Access Program Development

Systematic approach to launching software products with beta testers and early access clients.

## When to Use This Skill

- Launching a new product/feature
- Pivoting to a new customer segment
- Need validated case studies before public launch
- Want to refine product-market fit before scaling
- Need paying customers to fund development

## Core Framework

### Phase 1: Ideal Customer Profile (ICP) Discovery

**Step 1: Segment by Pain Level**

Score potential segments by:
- Pain level (how acute is the problem?)
- Accessibility (how easy to reach decision maker?)
- Speed to value (how quickly can they see results?)
- Willingness to pay (do they have budget for this category?)

**Step 2: Choose Primary Target**

The decision framework:
```
PRIMARY TARGET CHECKLIST:
☑ Pain is VISIBLE (they talk about it publicly)
☑ Decision maker is ACCESSIBLE (not buried in org chart)
☑ Sales cycle is SHORT (can get to yes/no quickly)
☑ Can become ADVOCATE (owner/founder with reputation on line)
```

**Step 3: Secondary & Tertiary Segments**

Document but don't prioritize:
- Usually larger/more complex segments
- Require longer sales cycles
- Save for after primary validation

### Phase 2: Market Research

**Research Channels (in order of confidence):**

1. **Warm Intros** (highest conviction)
   - "Who in your network fits this ICP?"
   - Offer referral fee for closed deals
   - Email template provided in references

2. **LinkedIn Sales Navigator**
   - Build target list of 100+ contacts
   - Filter by: Title, Company Size, Location, Activity
   - Connection acceptance rate: expect 10-20%

3. **Industry Communities**
   - Facebook/LinkedIn groups
   - Trade associations
   - Slack communities
   - Post valuable questions first, pitch later

4. **Events/Trade Shows**
   - Attend as researcher, not vendor
   - Ask about pain points before mentioning product
   - Collect business cards for follow-up sequence

**Research Checklist for Each Target:**
- ☑ PAIN SIGNALS (Do they post about the problem?)
- ☑ ACTIVITY (Are they active on LinkedIn/responsive?)
- ☑ COMPLEXITY (Decision maker accessible?)
- ☑ READINESS (Currently experiencing pain?)
- ☑ FIT (Meets all ICP criteria?)

### Phase 3: Outreach Sequences

**4-Message LinkedIn Sequence:**

**Message 1: Connection Request**
```
Hi [Name], saw you're with [Company]. Quick question:
[Market-specific question that hints at pain point]

Not selling anything, just researching how [segment] handles this.
- [Your name]
```

**Message 2: Follow-Up After Accept**
```
Thanks for connecting [Name].

Been talking to [segment] and hearing a consistent theme:
"[Pain point quote]"

Does that resonate with your situation or do you have a different approach?
```

**Message 3: Pain-Focus**
```
[Name], specific scenario:

[Consequence of not solving the problem]

Most [segment] I talk to: "[representative quote]"

Is that [describe] your experience or do you see it differently?
```

**Message 4: Soft Pitch**
```
[Name], been working on something that might help with [pain point].

[Product] is basically [one-sentence description]

Built specifically for [segment] who [detailed pain decomposition]

Worth a [time] call to see if it fits your workflow?
```

### Phase 4: Beta Tester Selection

**Score each candidate:**
| Criterion | Weight | Score |
|-----------|--------|-------|
| Pain signals | 1-5 | ☑-5 = talks about problem publicly |
| Accessibility | 1-5 | ☑ = can reach decision maker |
| Brand fit | 1-3 | ☑ = target vertical/segment |
| Timing | 1-3 | ☑ = actively experiencing pain now |

**Prioritize:** Score 9-13 for first outreach wave

### Phase 5: Program Structure

**What's Included (Free for 60 days):**
- Full platform access
- Integration help (we do the work)
- Unlimited usage
- Daily support (first week)
- Slack/email support (ongoing)

**What's Expected:**
- Connect account/data feed
- Approve/reject features/campaigns
- Biweekly feedback call
- Case study permission (if positive)
- Intro to 1 peer if satisfied

**Pricing Structure:**
- Early access: [30-60% discount off future pricing]
- Lock-in period: 12 months at discounted rate

## Pitfalls

1. **Don't target the wrong segment first**: Large enterprise may have budget but takes 6 months to close. Start with accessible, fast-moving segments.
2. **Don't skip the pain research**: If prospects aren't talking about the problem publicly, either your ICP is wrong or the pain isn't acute enough.
3. **Don't write generic messages**: "I'd love to connect" gets ignored. Lead with insight specific to their world.
4. **Don't give up too soon**: 10-20% LinkedIn acceptance is normal. 5-10% reply rate is good. Follow up 3-4 times.
5. **Don't assume agent can execute research directly**: LinkedIn Sales Navigator, ZoomInfo require user credentials. The agent can BUILD the framework (target lists, search queries, message templates) but the user must EXECUTE the actual lookups. Set this expectation clearly upfront. See `references/cannot-execute-research-workaround.md` for the hybrid pattern.
6. **Don't forget deployment step**: When building dashboards (Vercel/Notion) to support outreach, remember the user needs to actually deploy/publish it before they can use it.
