# Tales Untold Buffer Scheduling

## Buffer API Key
Saved in `.env` as `BUFFER_API_KEY`.

## Channels
- **TikTok** (primary target)
- **YouTube Shorts** (secondary)
- **Instagram Reels** (tertiary)

## Upload Workflow
1. Generate final video
2. Upload to Google Drive for user review
3. If approved, schedule via Buffer API
